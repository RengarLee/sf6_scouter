# 0.5.4 - 2026-11-14

### Added

- **Replay performance statistics in period reports**: View anti-air rate, combo count, average and highest combo damage, counter hits, punish counters, throw techs, and time spent in the corner from analyzed replays for the selected period and character. The card also shows the number of analyzed matches alongside the total matches in the period, so you can see how much of your play the statistics cover.
  <sub>🙌 Special thanks to QQ 痛饮三杯 and QQ 焕冥 for their replay review suggestions</sub>
- **Keep the overlay visible after exiting the game**: Turn off “Automatically hide the overlay when the game exits” in system settings to keep the Mini / Pro window visible after exiting SF6. Automatic hiding remains enabled by default.
  <sub>🙌 Special thanks to QQ 宇宙最强 for the feedback</sub>

### Improved

- **Clearer replay analysis queue status**: The analysis list now shows service maintenance notices, the number of tasks ahead, and a waiting-to-start message to help you follow unfinished tasks.

### Fixed

- **Removed inaccurate historical best results**: Removed the historical season-best display that used sample data on the game data page. The current character's highest-score summary and character rankings remain available.
  <sub>🙌 Special thanks to QQ 焕冥 and QQ PorUnaCabeza? for the feedback</sub>
